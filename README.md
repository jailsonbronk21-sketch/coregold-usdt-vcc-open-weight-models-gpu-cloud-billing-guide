#### 2. 开卡金额一定要预留“预授权 + 波动缓冲”
假设你预计今天跑 4 个小时算力需要 $18，千万不要只给卡片充刚好 $18.00。云平台扣款前可能先冻结 $1~$2 预授权额度，再加上实际运行时长波动，一旦可用余额差几美分，实例就会被强制挂起甚至清盘。**建议开卡时多留 $3~$5 缓冲余额。**

#### 3. 用单卡余额做“算力熔断器”

#### 4. AVS 账单地址务必与卡片详情页完全一致
